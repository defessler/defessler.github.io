wlm:~$ wlm --tutorial basics

The main window

Profiles live in the left sidebar; the selected profile's windows fill the right pane. Every row shows the app, its title at save time, and where & how it restores — monitor, virtual desktop, size, position, and state.

The Coding profile: six windows across two monitors and two virtual desktops.

  • ⌨ chip next to a profile — it has a global hotkey.
  • ● / ○ dot — bound / not bound to a monitor setup (see auto-activation).
  • Footer hints — the whole app drives from the keyboard: j/k to move, Enter to load, / to filter, ? for the full map.

wlm:~$ wlm --tutorial profiles

Saving & loading layouts

Arrange your windows the way you like, hit + new profile, name it — done. WLM captures every visible window's position, size, state (normal / minimized / maximized), monitor, and virtual desktop.

  • Load puts every captured window back — even after apps restarted, titles changed, or Windows shoved everything onto one screen. The matcher re-finds windows by process, class, title signature, owner identity, and position.
  • Update re-captures the current arrangement into the selected profile (your hotkey, binding, and history are preserved).
  • Load details shows a per-window report of the last load — what matched, what moved, what was missing.
  • Apps that open their windows late (IDEs re-floating tool panels, Electron apps) are re-applied automatically for up to ~2 minutes after a load.
Profiles are plain JSON in %APPDATA%\window-layout-manager\profiles (the FOLDER button opens it) — hand-editable, with schema autocomplete in most editors.

wlm:~$ wlm --tutorial hotkeys

Global hotkeys

Click the hotkey chip on any profile to bind a system-wide shortcut. Press the combination you want — WLM records it live and warns about conflicts with other profiles or the auto-activation hotkey.

Hotkeys fire from anywhere — no need for the WLM window to be open.

wlm:~$ wlm --tutorial visual

The visual editor

Switch the view to VISUAL for a live minimap of your saved layout: monitors to scale, one tab per virtual desktop, every window draggable.

Drag to move, corner-drag to resize; edges snap to monitors and other windows (Alt disables snapping).

  • Select a window to get Edit / Block app / Remove in the panel below the canvas.
  • Drag a window between monitors — its target monitor and relative position update automatically.
  • Edits auto-save after a beat; the unsaved badge tells you when a write is pending.

wlm:~$ wlm --tutorial editing

Precise edits, undo & history

The EDIT button (list view) or Edit panel (visual view) opens exact fields for any window: desktop, monitor, state, and pixel-perfect X/Y/width/height.

  • Ctrl+Z / Ctrl+Y — undo/redo any edit, with a labeled trail.
  • Ctrl+H or History — browse and restore full saved versions of the profile (every Update keeps a snapshot).
  • Windows tracked live (see Hold mode) also keep a per-window position history you can roll back individually.

wlm:~$ wlm --tutorial auto-activation

Monitor binding & auto-activation

Bind a profile to your current monitor setup and WLM can restore it by itself whenever that setup reappears — docking the laptop, starting a Parsec session with a virtual display, plugging into the projector.

  • Triggers — on monitor change, at app launch, and/or a dedicated hotkey. All off by default; you opt in.
  • Best-guess remap — when your monitors almost match a saved setup, WLM picks the closest mapping, applies it, and remembers the decision so it never asks twice.
  • The Status panel logs every decision auto-activation makes, so you can always see why a profile did (or didn't) fire.

wlm:~$ wlm --tutorial hold

Hold mode

The Hold layout toggle (next to the hotkey chip) pins a profile as the live layout. While holding, WLM watches your windows a few times a second:

  • An app moves or resizes its own window? It's put straight back.
  • You drag a window yourself? WLM records the move into the profile instead of fighting you — your layout evolves as you work.
  • Loading a different profile releases the hold automatically; explicit action always wins.
Hold is ideal for apps that "helpfully" reposition themselves after fullscreen games, RDP sessions, or monitor sleep.

wlm:~$ wlm --tutorial desktops

Virtual desktops

On Windows 11, profiles capture which virtual desktop each window lives on, and Load sends every window back to its desktop — creating missing desktops if the profile needs more than currently exist. The visual editor shows one tab per desktop; the per-window editor lets you reassign a window to any desktop, or leave it unmapped to stay wherever it is.

wlm:~$ wlm --tutorial keyboard

Command palette & keyboard

Ctrl+K opens the command palette: every action and every profile, fuzzy-searchable.

  • Vim-style navigation everywhere: j/k, gg/G, / filter, Tab to switch panes.
  • Single-key actions on the focused profile: Enter load, r rename, d delete, n new.
  • ? shows the complete keyboard reference.

wlm:~$ wlm --tutorial updates

Updates

WLM checks this site's update feed on launch and on a schedule you control. When a new build is out, a badge appears in the title bar; one click downloads, verifies the file against its published size and sha256, and swaps the new build in place.

wlm:~$ wlm --tutorial blacklist

Blacklist

Keep noise out of your captures. Rules match on process name, window class, or title — the Block app button in the visual editor adds one in a click. Blacklisted windows are ignored at save and at load.

wlm:~$ wlm --tutorial companions

Companion software

The Companion tab detects complementary tools — PowerToys for live drag-snap zones, virtual display drivers for headless monitors, Windows Terminal and PowerShell 7 for scripting — and offers one-click installs for whatever's missing.

wlm:~$ wlm --tutorial cli

CLI, links & automation

  • WindowLayoutManager.exe --load="Coding" — load a profile from a script, Task Scheduler job, or Stream Deck button. Works whether or not WLM is already running.
  • wlm://load/Coding — the same, as a clickable link. wlm://show raises the window.
  • Taskbar jump list — right-click the WLM taskbar icon for one-click profile loads.
  • Post-load hook — a profile's JSON can carry a postLoad command (e.g. switch an OBS scene) that runs after a successful load.
  • WLM lives in the tray: closing the window keeps hotkeys, hold mode, and auto-activation running.
