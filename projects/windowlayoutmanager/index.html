  • Layout profiles - Capture every window's position, size, and state. Restore with one click, a global hotkey, or the CLI.
    • 
            
  • Monitor-aware - Profiles bind to monitor sets and auto-activate when your displays change: docking, streaming with a virtual display, plugging into a projector.
    • 
            
  • Smart re-matching - Tries to find the right windows again even after apps restart, titles change, or Windows shoves everything onto one screen.
    • 
            
  • Virtual desktops - Windows go back to the desktop they were saved on.
    • 
            
  • Hold mode - Pin a layout live. If an app moves its window, it gets put back.
    • 
            
  • Visual editor - Drag windows around a minimap of your monitors, with snapping, undo/redo, and per-window history.
    • 
            
  • Scriptable - --load="Profile" from the command line, wlm:// links, and the taskbar jump list.
    • 
            
  • Self-updating - Checks this page's feed, verifies the download by size + sha256, and swaps itself in place.
    •
