How to read it

  • Decode is generation speed and tracks memory bandwidth. Prefill is prompt processing and tracks compute; it dominates wait time on long prompts.
  • “Decode + spec” uses speculative decoding (MTP, DFlash2 and similar), which multiplies speed 1.6–2.8×. Never compare it against plain decode.
  • The 27B columns mix Qwen3.6-27B and Qwen3.8-27B, which are close in size but not identical. Turn on test conditions to see which was used.

What’s comparable

Different testers, builds and runtimes produced these numbers. The cleanest like-for-like sets are Hardware Corner (5090, 3090, V100), Tom’s Hardware (M5 Ultra, DGX Spark), The Register (RTX Spark, DGX Spark, Strix Halo) and the llama.cpp 7B scoreboard columns.

Runtime choice can swing results 2× or more: MLX vs llama.cpp on Mac, vLLM vs llama.cpp on GB10, Vulkan vs ROCm on Strix Halo.

Left out

A reported 14–17 tok/s for 70B on RTX Spark and widely repeated 40–52 tok/s claims for 70B on M5 Ultra both exceed what those chips’ memory bandwidth allows, so they aren’t in the table.
