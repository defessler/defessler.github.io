Games the Models Built

Six playable games written by local models on one RTX 5090, from the September 2026 games bake-off: the same three prompts, five model configs, and a referee that only calls a game playable when it survives an attempt to break it.

BeginnerIntermediate

On 2026-09-17 we asked five model configurations on one RTX 5090 to build the same three games: Conway’s Game of Life, Tetris, and a Super Mario-style platformer. One request per game, one self-contained HTML file per answer, decode speed taken from the server’s own per-request timings. Then referee agents read every file end to end and tried to break the claim that a human could play it. The default verdict was broken, and only code that survived that attempt gets called playable here. Click any game and use its keyboard controls.

The full scoreboard, including the multi-agent arm and every concrete failure the referees found, lives on The Models DokiDex Runs and in docs/scorecards/2026-09-17-games-bakeoff.md.

How these were graded

Every file went through two independent passes. An inspector extracted the JavaScript and ran it through node --check, rendered the page headlessly with five seconds of virtual time so the game loop actually ran, and checked a fixed mechanics list per game. Then a referee read the entire source and tried to refute playability: wrong neighbor counts, collision indexing slips, rotation built from the wrong matrix dimension, spawn points over pits, restart buttons that call a function that was never in scope. A game appears on this page only if it survived both.

The one finding worth carrying beyond this page: the multi-agent protocol didn’t lift the smaller models. Two draws from the plain 35B model beat five orchestrated calls from either smaller config, at a fraction of the tokens. When a model systematically writes a bug, its own critic round ships the same bug twice.
