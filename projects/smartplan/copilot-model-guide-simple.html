Quick picks

  • Writing code - GPT-6 Luna, behind a scripted check. For judgment calls, use GPT-6.1 Sol on Pro+ and up, or Sonnet 5.5 on plain Pro. GPT-6.1 Sol needs CLI 1.0.90 or later. On an older build, use GPT-6 Sol instead. Neither GPT-6 pick has been trialed here.
  • Code reviews - Gemini 3.8 Flash. In T42 it caught 13 of 16 seeded C++ defects for 5.8 credits. GPT-5.6 Terra caught the same 13 for 41.7 credits. If the budget allows, GPT-6 Sol caught 14 to 15. On the tightest budget, a fresh Luna re-runs the scripted check on its own simple work.
  • Writing docs - Sonnet 5.5 for technical reports. Use GPT-5.6 Terra until it leaves Copilot on 2026-11-16. Pick Opus 5.5 when the prose is the product, though only one writing board lists it so far.
  • Exploring a codebase - Use GPT-6 Luna or GPT-5.6 Luna to find things. Haiku 5.5 serves at the same price. Use Sonnet 5.5 to understand what you find. On Pro+ and up, GPT-6.1 Sol reads long context better at the same list price.
  • Planning and architecture - Opus 5.5 on Pro+ and up, with Opus 5 as the pricier fallback
  • Don't want to pick - "Auto" routes each request to a model. It shows as Copilot Fusion in the CLI, VS Code and the app. On a paid plan it takes 30% off through 2026-11-30. The 10% Auto discount now covers Chat and cloud agent only. Pin a model when the tier matters. On Pro+ and up, Auto can send a hard prompt to GPT-6 Astra at 10 / 50.

The table

Models are grouped by what a task costs, not by list price. AA measures dollars per task on its own index run. That count includes every input, cache and reasoning token, so list price can mislead you. Grok 4.7 lists at 2 / 6 but costs $2.73 a task, twice Opus 5.5.

Good at compares a model only with the others in its band.

  • ★ best in its band at that job
  • ✅ within 1.5 points of the best
  • 🟡 within 3 points
  • 🟠 more than 3 points behind
  • ❌ wrong tool: the registry never seats this model for that job, whatever it scores
  • ? no AA row, so no score

So a ★ on a budget model means best for the money, not best overall. Hover a mark for its score out of 10. For the absolute picture, read the grades and scores below the bands.

Value is quality divided by cost. It's AA's Intelligence Index (the bracketed number) divided by its measured dollars per task. GPT-6.1 Sol, GPT-6 Sol, Sonnet 5.5 and Sonnet 5 all list at 2 / 10, yet their values are 224, 161, 69.5 and 28.1. Eleven models lack a measured AA row at Copilot's default effort. They use the nearest row or the only one, and the tooltip names which. A max row flatters the index and inflates the cost. — means AA has no measured cost. Click a header to sort within a band. Fine print

¹ Pro+/Max only. GitHub documents Opus 5 and Opus 4.8 this way too, though both served on a plain Pro account on 2026-07-25 (T30). On base Pro a gated model falls back to a Sonnet with a printed warning. Check what your plan serves.

How the scores are computed. Every score comes from one AA row per model, the same row the Value column reads, taken from AA's leaderboard dataset on 2026-10-13. Each column averages a few of AA's evals:

  • Writing code - Terminal-Bench 4.0 and SciCode.
  • Writing docs - GDPval, which grades real work files from 44 occupations. It's one board, so treat this column as the thinnest.
  • Code reviews - the two coding evals plus AA's non-hallucination rate, since a reviewer has to find bugs without inventing them. No public board scores code review directly. This repo's review trials (T16, T18, T34, T42) are in the Watch out notes instead.
  • Research - Humanity's Last Exam, AA's long-context reasoning eval, and its knowledge-accuracy eval.
  • Planning - the Intelligence Index itself.

Cost bands and the value fit both use AA's measured cost per task. MAI-Code-1.1-Flash has no AA row, so it gets a band from its list price and a ? wherever no role rule applies.

Where the ❌ marks come from. They follow the registry's tiers and seats, not the scores. The Fables only plan. Mechanical-tier and cheap unclassified models never plan. MAI-Code-1.1-Flash and Kimi K2.7 Code are scoped to coding by their own vendor cards.

Scores aren't trials. Sonnet 5 scores low at medium effort on these boards. Its Mid seat rested on this repo's own trials (T32, T33), which put it through real briefed work. Sonnet 5.5 took that seat on 2026-09-28 by the newest-version rule, with no trial of its own yet. scripts/good-at.py computes every mark from research/2026-11-11-good-at-data.json, and check.sh gate (y) fails the build if this page drifts from it.

Effort. Most value rows read medium. At low effort, AA scores both Lunas lower and cheaper. Their indexes are 20.9 and 21.0, at $0.0045 and $0.0098 a task. Both solved 0 of AA's 198 Terminal-Bench 4.0 attempts at that effort.

Cheap models fail silently. Only put them on work something else checks.
