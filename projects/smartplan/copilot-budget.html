Copilot on a Budget: Getting the Most from a Low Credit Allowance

This page is meant as a quick reference on practical cost control for GitHub Copilot CLI. The model guide tells you what to pick. This page tells you how to spend less once you've picked. Rates, rosters, and CLI behavior were last read 2026-09-22 to 2026-09-30 from the sources at the end.

How Copilot Billing Works (the Mental Model)

Since 2026-06-01, usage is token-metered in credits worth $0.01 each. Pro+ costs $39 a month for 7,000 credits, worth $70. That's 3,900 fixed base credits plus 3,100 flex credits GitHub calls variable and "designed to adapt". Pro splits 1,000 base plus 500 flex. Max splits 10,000 plus 10,000. Allowances reset at 00:00 UTC on the first of each month, whatever your billing date. Four things drive the bill:

  • Which model - Sonnet 5.5 and Sonnet 5 run $2/$10 per 1M in/out (see the GitHub pricing table). Haiku 4.5 is half that. GPT-6 Luna, GA on every paid plan since 2026-09-22, is the cheapest Copilot-dispatchable model on every axis at $0.10/$0.50. Haiku 5.5 (GA 2026-10-07) matches that on prompts to 100K tokens and scores far higher. Stable CLI 1.0.94 and later list it. It backs Luna on the Cheap implementer seat (T46). GPT-5.6 Luna is $0.20/$1.20. GPT-5 mini left Copilot on 2026-10-19. Pro+ and up add GPT-6 Sol and GPT-6.1 Sol at Sonnet's price and Opus 5.5 at $4/$20. Opus 5 and Opus 4.8 are $5/$25. Fable 5 (legacy since 2026-09-07), Fable 5.1, Opus 4.8 fast mode, and GPT-6 Astra's lower tier are $10/$50. Anthropic removes Opus 4.8 fast mode on 2026-11-30. Requests then error rather than fall back. Astra tops out at $20/$75 past 272K tokens.
  • How much context - the trap. The whole context is re-read every turn at the cache-read rate (~$0.2/M on Sonnet). A big one is paid per turn.
  • How many turns - each extra round re-bills that context.
  • How much output - output bills at ~5× input, reasoning and thinking tokens included.

A small, clean task run inline on Sonnet costs ~8.5 to 13 credits. A real feature runs 20 to 50 (a two-file UE5 feature we measured came in just over 19). Pro+'s 7,000 credits cover roughly 150 to 400 real tasks if you avoid the accidents below.

The Levers, Ranked by Impact

  1. Don't fan out ordinary work. Fan-out splits one task across several agent sessions, for example with /fleet. On a task that fits in one context it cost 2.3 to 4.2× more credits than inline, at identical quality (T22 to T24). The tax is highest on small, easily parallelized modules. Fan out only for work bigger than one context, or for failure-prone work.
  2. Right-size the model. Don't leave the session on a premium one. Run the session on GPT-6 Luna and ask before anything above it.
  3. Send mechanical work, and any coding leaf outside a never-Cheap class (concurrency, UB, templates, security, determinism/serialization), to GPT-6 Luna first, with a verifier on its work. At Copilot's default medium effort, Artificial Analysis scores it 29.5 against GPT-5.6 Luna's 25.0 and Sonnet 5's 28.1, at about $0.02 a task against Sonnet 5's $1.00. We haven't trialed it yet. A Pro+ probe served it on CLI 1.0.83.
  4. When a fix fails twice, move up to the Mid seat: GPT-6.1 Sol on Pro+ and up (CLI 1.0.90 or later), Sonnet 5.5 otherwise. Sonnet 5.5 shipped on 2026-09-28 at Sonnet 5's price. AA scores it 40.7 at medium, for about $0.59 a task.
  5. One older cheap model is worth an A/B trial while it lasts. GPT-5 mini's one measured run cost about 39% of Haiku 4.5's. It retires from Copilot on 2026-10-19. Kimi K2.7 Code left on 2026-10-02.
  6. Save Opus for a hard one-shot plan, and Fable or fast mode for the single hardest decision.
  7. Turn on Auto for a discount on paid plans. In the CLI, VS Code and the app, Auto now shows as Copilot Fusion: 30% off model costs on paid plans through 2026-11-30 (Fusion Standard on Pro, High and Max on Pro+ and up). The 10% Auto discount now applies in Chat and cloud agent only. Auto picks a model per request by task complexity. Since 2026-09-14 the CLI offers three tiers (Efficiency, Balance, Intelligence). Efficiency suits ordinary mechanical work. From CLI 1.0.87 you can make it the tier every session starts on. An org policy can set it too. The changelog doesn't name the setting key yet. Pin an explicit model only when you're deliberately tiering a fan-out.
  8. Keep context small and sessions warm. Scope the session to the files you're changing, not the whole repo or big headers. For follow-ups, copilot --resume <id> rides the warm cache instead of re-paying the cold context. We measured that at ~14k tokens bare and 75 to 160k with a skill tree loaded.
  9. Terse output, low effort on mechanical turns. Use --effort low (or none/minimal, where the model supports them) on boilerplate, since reasoning tokens are output-priced at $10/M on Sonnet. For named subagents, put reasoningEffort: low in the mechanical agents' frontmatter. It applies on dispatch and, since CLI 1.0.88, on selection. We haven't tested either on a paid plan. Don't pin it under subagents.agents.<name> in the repo's .github/copilot/settings.json, which silently ignores every subagents.* key. That key is documented for user settings only.
  10. Cap the runaway tail: it's the #1 budget accident. One uncapped blind-repair spiral burned 167 credits in a session of ours. Put --max-ai-credits (or /limits) on a session so a loop can't run away. When a fix fails twice, stop and diagnose instead of retrying. Note: don't cap a session that should load a skill. A cap can make the model skip the skill to save budget. Cap the fan-out leaves (each subagent's unit of work) instead. A cap can't go below 30 credits. Since most leaves we've measured cost 1 to 13, a per-leaf cap catches only a runaway past 30. GitHub's docs disagree on whether /limits caps each response or the whole session.
  11. Script anything deterministic. A shell script costs zero model calls.

Budget Killers (the Anti-Patterns)

Skip any lever above and it costs you. Auto adds one more trap. On Pro+ and up it can send a hard prompt to Opus 5.5, Opus 5, Opus 4.8, or GPT-6 Astra. All of them are priced well above the session model. GPT-6 Sol and GPT-6 Luna joined Auto's pool too (read 2026-10-20). Stable CLI 1.0.89 (2026-09-28) lists GPT-6 Sol and GPT-6 Luna in its model picker and names claude-opus-5.5. Prereleases 1.0.89-1 and 1.0.89-0 carried them first. Stable 1.0.90 (2026-09-30) adds GPT-6.1 Sol and also names claude-sonnet-5.5.

Watch the Meter

  • /usage - session credits, a monthly plan bar, and an activity graph. Since CLI 1.0.85 it also lists per-model credit rows, which we haven't seen live yet. The token breakdown (input, output, cached) renders inconsistently. Restarting with copilot --resume makes it appear.
  • /statusline with ai-credits (month) plus ai-used (session) - always-on spend visibility.
  • /context - a per-source breakdown of what's using the context.

One Caveat for Budgeting

Sonnet 5's $2/$10 launched as introductory pricing. On 2026-08-10 Anthropic made it the standard price and dropped the rise to $3/$15 scheduled for 2026-09-01. GitHub lists it as standard too. Nothing here needs re-costing.
