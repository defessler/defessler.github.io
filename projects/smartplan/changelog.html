2026-10-13 · No model grade is required anywhere (v4.148.0)

The author asked that no part of smartplan require a specific grade of model. Offering one is fine. Requiring one isn't.

Every tier is now offered, never required. SKILL.md carries the rule on the inline route, and routing.md, flow.md, check.md and modes.md each point at it. A tier the user declines, or one the plan doesn't serve, falls to the strongest model on offer at or below the seat. The work leans on the executable oracle first, verifies in a fresh context, and names the gap at the gate and in the verdict. Judgment that reader can't settle comes back UNKNOWN for the human.

A Cheap seat no longer stops. It used to write the brief, stop, and name the session model to switch to. Now it writes the same brief, offers that model, and carries on at its own tier. The spiral diagnosis, the verify and a fail-twice retry run at its tier, and a Cheap session with no stronger planner plans the wave itself, flagged at the gate. It still never dispatches above its own price, so the cost ceiling is unchanged.

The fail-twice rule has an end that isn't a stop. On a no, or on a Cheap seat, the leaf gets one fresh retry at the top tier allowed, then comes back as the best attempt with its caveats. Below Strong, an Opus strike-out goes to the orchestrator with a stronger session offered.

The seats follow. The Claude Code verifier judges on whatever model the dispatcher can reach when Opus isn't on the account. Copilot's Cheap implementer and Cheap verifier take a never-Cheap leaf when the brief says the stronger seat was declined. cpp-gamedev-check.md, smartreview's breaking hunt and the GLM and local-model notes say the same. Four eval graders that passed a stop now fail it.

The Claude Code Cheap seat's body still said it ran on Sonnet. It says Haiku now.

2026-11-02 · smartdiff joins the family, with a semantic diff for Unreal Blueprints (v4.152.0)

A seventh skill, smartdiff. It renders a session's changes, from git or Perforce, as one self-contained HTML review page with per-file intent notes. It started as a session-diff skill the author handed over, and it installs as an optional companion like smartdiagram.

Blueprints get a real diff. A .uasset used to read "binary file". bp_prepare.py now pulls each old revision, and bp_export.py dumps both revisions to T3D text inside a headless UE editor. The page then lists graph by graph what changed: nodes, wires, pin defaults, variables, components and class defaults. Checked against UE 5.8 on a test project and on Cropout's BP_Player.

The page matches a Rider diff. Dark by default, with green added lines, blue modified lines and grey removed ones. Changed lines pair by similarity rather than position. The file list hides with f or a Files button.

Gate (k)'s cap rises to 2,816B for the seventh description, with the dated rationale in docs/v4-rule-inventory.md. Oracle stage (k) runs smartdiff's renderer against a small Blueprint fixture.

2026-11-02 · smartdiff reviews only the agent's own edits, on Copilot CLI and Claude Code (v4.153.0)

Agent-only mode. trail.py exports the edits the agent made and nothing else, read from the session record rather than the working tree, so a teammate's change or a hand edit can't leak into the review. It scopes to the last message, the last N messages or the whole session. It reads Copilot CLI sessions (apply_patch, edit and create) and Claude Code transcripts (Edit, Write and subagent edits), and finds the running session by itself. A change it can't prove from recorded evidence is left out and named, and the run exits 2. It ships the before and after files, a plain diff, the prompts and a transcript beside the page. Checked live on both harnesses: a real Copilot CLI edit session, and this repo's own Claude Code session, where every reconstructed file matched the live copy.

The page gains an expandable diff. a or a click on a hunk header shows the omitted lines between hunks. b or a chevron hides the file list, with f kept as an alias. Free functions, static calls, format strings and Unreal export macros get their own colors. diffview.py --git-context <repo> reads whole files from git so a normal session diff can expand too.

Oracle stage (k) now also runs a 31-case trail self-test.
