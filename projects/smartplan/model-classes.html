Model Classes

Generated 2026-10-08 by scripts/model-classes-page.py from the class registry, the seat files and a dated data read. Every model smartplan tracks, the class it may work in, and the measured score behind it.

How a class is set

A class comes from one measured number: the model's best Artificial Analysis Intelligence Index. AA's estimated scores don't count. A model takes the highest class whose anchor it matches or beats. Each anchor is the model this repo has actually run in that role.

Class Anchor AA index What it may do
Reasoning Opus 4.8, planner and verifier in benchmark T27 41.8 Plan, verify Mid and Strong work, take escalations. A Mid seat too, when it costs no more than that seat's Implementer pick
Implementer Sonnet 5, implementer and small-plan planner in T17, T27 and T35 38.2 Briefed or correctness-sensitive leaves, verify Cheap leaves, plan small jobs
Mechanical Haiku 4.5, Cheap leaves in T27, T32 and T35 16.9 Mechanical leaves behind a verifier, scouting, running a scripted check
Unclassified none none No seat. A deliberate trial only

Price, vendor benchmarks, succession and author direction never set a class. Near an anchor, a point is inside the board's noise, but the rule still applies strictly. AA measures full-precision weights, so a local Q4 quant scores at or below its row.

Reading the table

  • AA index and AA TB4 % (AA's own Terminal-Bench 4.0 run) are at the model's best measured effort, usually max.
  • $ per AA task is what AA paid per index task at that effort. It folds in how many tokens a model spends, so it compares real cost better than list price does.
  • Copilot picker is GitHub's own label from the Copilot model catalog: Powerful, Versatile or Lightweight. Each model gets exactly one.
  • Seat comes from the seat files. On Copilot the session runs GPT-6 Luna, and a seat above it runs only after you say yes.

Effort changes the answer

Cost and quality move a lot with effort, so the seat picks use these rows, not just the best one. AA's TB4 puts GPT-6 Luna at max five times above medium, but on this repo's own coding tasks (T42, T43) medium matched max at under a third of the credits, so Copilot runs it at medium. Astra at xhigh matches Opus 5.5 at max on TB4 for well under half the cost, so it holds the Copilot Reserve. GPT-6.1 Sol still meets the Reasoning bar at low, so both Sol seats run it there.
