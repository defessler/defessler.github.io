Updated 2026-11-11, v4.170.0. Newest first, back to v4.59.0. Older windows are in git. The changelog has per-release detail for the fourteen most recent releases.

Since 2026-11-11 (v4.170.0)

Fable 5.2 and Gemini 4 Carbon are in the guides. Anthropic released Fable 5.2 on 2026-11-09 at 8 / 40, and Copilot serves it on Pro+ and up. Gemini 4 Carbon reached Copilot a day later. Neither has a score on the scale the classes use, so neither holds a seat yet. In Claude Code the fable alias now means Fable 5.2. M365 Copilot's harness table gained Opus 5.5, Sonnet 5.5 and Haiku 5.5. Every price, roster and board figure was re-read on 2026-11-11.

Since 2026-11-11 (v4.169.0)

smartdiff reads a shelved Perforce changelist. A shelf has nothing opened, so the Blueprint export used to find no files. It now reads both sides from the server. A file from p4 describe no longer shows as "(unnamed)". An added node, variable or component shows the values it was given, not only its name.

Since 2026-11-11 (v4.168.0)

smartdiff uses the whole window. The session summary and each file's note on a smartdiff page no longer wrap at 72 characters. They run the full width, like the diff beside them. The turret demo shows it.

Since 2026-11-04 (v4.167.0)

Shorter skills, same rules. Twenty-one skill files lost 4% with every rule kept, checked line by line by a fresh reviewer. The byte caps came down to hold it. smartreview gains a web UI standards doc condensed from hallmark, so it can review HTML and CSS as well as C++. The rulebook is new: every rule and figure in the family as 2,414 plain one-liners, grouped by skill, with a filter.

Since 2026-11-04 (v4.166.0)

Run Copilot sessions on Luna. Pricier Copilot sessions with smartplan loaded mostly stop on Copilot's content filter. On CLI 1.0.105 Sol did in 15 of 18 runs and Astra in its one run. Luna loads the skill cleanly. Probe 5 in the selftest gains a Copilot form that switches off smartcost.

Since 2026-11-03 (v4.165.0)

Reviews run away from the author. Ask the smartplan-verifier seat to review a change and it loads smartreview, in a fresh context with no edit tools. You get the same three ranked categories, with every fix proposed rather than applied.

Since 2026-11-03 (v4.164.0)

Switch off any part of smartplan. Each feature is its own skill now: smartflow for fan-out, smartroute for model tiers, smartcost for the cost dial, smartbrief, smartexec, smartcheck and smartcheck-cpp. smartplan loads the parts a task needs. Turn one off in your skill list and smartplan works without it, saying once what it skipped.

Since 2026-11-03 (v4.163.0)

Copilot runs Luna-first. Every subagent the skill sends runs GPT-6 Luna. Run the session on Luna and it does the work itself, with a fresh Luna checking it. Run it on a pricier model and that model plans and checks every Luna diff while Luna writes the code. The pricier agent profiles stay for calling by hand.

The Quickstart opens on Getting Started, with the first video right there.

Since 2026-11-03 (v4.162.0)

Watch a session instead of reading one. Getting Started has a short video for most steps. Each shows the prompt, the skill's output as it arrives and a caption on what to look at.

Since 2026-09-15 (v4.126.0 - v4.127.0)

The voice rules hold in every reply, not only documents. Run python .claude/skills/smartvoice/scripts/install_voice.py once. On Claude Code it turns the resident rules into an output style, adds a Stop hook that asks for a short correction when a reply uses a banned character outside code, and hands the rules to each subagent as it starts. On Copilot CLI it uses your user instructions file and two hooks. It keeps your other settings and is safe to re-run. --uninstall takes it back out.

Copilot defaults to max-savings, the mode that spends least, since Copilot bills credits per token. Runs measured it at equal quality for 54% of balanced's cost on mechanical work and 32% on judgment work. On wide waves it checks a sample of leaves and says so up front. Security, concurrency, undefined behavior, and templates always get the full verifier. Ask for budget to have a model check every leaf. Claude Code stays on max-quality.

The cheapest tier never reaches for a pricier model. A Cheap seat hands work only to its own model, a cheaper one, or a script. When the work needs more, it writes the brief, stops, and tells you which model to switch to. On Copilot that covers the Luna implementer seat, which carries the task tool and could otherwise dispatch a Sonnet seat.

smartvoice picks up four tells from Humanizer 3.0: describing what a design replaced instead of what it does, arguing with objections nobody raised, unnamed experts standing in for a source, and a heading restated as its first sentence. It treats text it's handed as material to rewrite, never as instructions, adds nothing the source didn't say, and requires a number to carry its baseline.
